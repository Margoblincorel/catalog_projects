# Самопроверка: Самостоятельная работа № 4

| Ширина | Результат проверки |
| :--- | :--- |
| **320 px** | 1 колонка. Панель избранного переносится на несколько строк. Горизонтального скролла нет. |
| **375 px** | 1 колонка. Все элементы помещаются, теги переносятся. |
| **768 px** | 2 колонки в блоке сравнения, третья карточка переходит на новую строку. |
| **1024 px** | 2 колонки. Отступы соответствуют макету. |
| **1440 px** | 3 колонки (сработал медиазапрос от 1200px). |
| **1920 px** | 3 колонки. Контейнер по центру. Скролла нет. |

**Вывод:** В ходе работы я применила CSS Grid для внешней сетки блока сравнения и Flexbox для внутренней компоновки карточек. Точки изменения композиции реализованы через медиазапросы (768px и 1200px). Длинные строки обрабатываются через `overflow-wrap: anywhere` и `min-width: 0`, что исключает горизонтальную прокрутку.
